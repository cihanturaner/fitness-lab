# V3.3.1 — focused patch on V3.3

Date: 2026-09-24. Supersedes V3.3 only where stated; the V3.1/V3.2 visual identity, navigation
and motion stay. No PR/e1RM features, meal database, sync or new dashboard.

## 1. Change exercise: approved, existing, or typed

- The Change panel of a draft slot offers the slot's approved substitutes, a search over
  existing exercises, and — when the typed text names no exercise yet — **Use “<Name>” for
  this workout**. Enter picks the typed name (or the only match).
- Name rule (`domain/exercise_names.py`, mirrored in `web/src/lib/exerciseNames.ts`):
  whitespace trimmed and collapsed; an all-lowercase entry is title-cased ("triceps curl" →
  "Triceps Curl"); any other casing is kept ("EZ-bar curl"). Identity comparison is case- and
  whitespace-insensitive (name, no equipment): an existing active identity is reused (an active
  one wins over a retired one spelled alike); a retired one is refused, never revived;
  otherwise one is created.
- `PUT /api/workouts/{id}/slots/{slot}/typed-exercise {name}` finds or creates and substitutes
  in one transaction. Only that workout changes (`workout_slot_substitution`); the package,
  its slots and every other occurrence keep the planned exercise.
- History shows both identities: "Performed: Triceps Curl" / "Planned: Cable Pressdown".

## 2. Independent planned slots (migration 0008)

- `performed_set_slot` (association table; `performed_set` and `workout` untouched, M1 §17)
  records the planned slot a set was recorded in, or `slot_id` NULL for extra work. It names a
  slot, never a `planned_set` (M2 invariant 8 stands). Composite keys and triggers: the slot is
  of the workout's origin; the set is of the workout and of the exercise the slot is performed
  as there; a placement never changes; nothing changes while complete; a placed set keeps its
  exercise and a slot keeps the exercise of its placed sets.
- `domain/placement.py` is the one rule: a placed set belongs to its slot; a set recorded as
  extra stays extra; a set with no placement row (recorded before 0008, or via the API without
  `slot_id`) keeps the pre-0008 rule (first slot performed as its exercise). Nothing is
  backfilled.
- The screen adds every set with its `slot_id` (null for extra work). Changing a slot's
  exercise after sets were recorded leaves those sets as extra work of their own exercise —
  never counted in the new exercise, never moved into another slot.
- Entry, the day timeline, Home's last session and exercise history group by slot: two slots
  performed as one exercise are two blocks / lines / exposures, each with its own planned
  exercise, sets and counts; "vs previous" compares a slot with the same slot earlier.
  "Sets are recorded under exercise N above" is gone.

## 3. Macro target as a setting

- Nutrition shows one line — "Current targets: 150P · 300C · 60F / 2340 kcal" (the target in
  force today, a scheduled next one beside it) — with **Edit targets** (P / C / F, kcal always
  P×4 + C×4 + F×9, effective from today unless changed) and **History (N)**. The day form holds
  only what was eaten; a past day notes the target it was judged by.
- The weeks 1–2 exception is asked only to change an **established** target: one already in
  force before today. The first target (none yet, set today, or only scheduled ahead) is setup.
- Storage unchanged: `macro_target` stays append-only and effective-dated.

## 4. Settings › Program in Turkish

For the locked program (Turkish notes' source hash matches): section aside, "Sürüm",
"Aktifleşme tarihi" (a Turkish date), the Turkish program name, the rules intro and every rule
heading/value ("Hafifletme Haftası (P1)", "12. Hafta (P2)", "1–11. Haftalar", "Performans öncesi
yük azaltma", a substitute's source condition). Exercise names, RIR, P1/P2/P7′, the e1RM
formula, numbers and source status codes stay verbatim. Other programs are shown as imported.

## 5. History

The day timeline is the only primary History view; the Sessions view is removed (`#/sessions`
opens the timeline). Exercise history is a secondary link ("Exercise history →", back with
"← Day by day"), not a tab.
